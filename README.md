# Мониторинг цен

Заполняет таблицы мониторинга ценами магазинов (М.Видео, DNS, МТС, samsungstore, Ozon, Wildberries) и подсвечивает красным, где конкурент дешевле НОСИМО. Исходные таблицы не меняются: результат — копия в папке «Мониторинг <дата>» рядом с логом и скриншотом.

Руководство пользователя — `docs/guide.html` (кнопка «Справка» в приложении).

## Приложение «Мониторинг цен»

- **Mac** — SwiftUI (`app/`). Из папки проекта: `Мониторинг цен.app`; самостоятельная сборка: `./build_dmg.sh` → `dist/Мониторинг цен.dmg`.
- **Windows** — Qt (`desktop_app.py`). Установщик собирается на Windows: `powershell -ExecutionPolicy Bypass -File build_windows.ps1` (Python 3.12 + Inno Setup 6) или в GitHub Actions («Сборка для Windows»).

Окно: таблица (тип ТВ/Смартфоны определяется по заголовкам), галочки магазинов, папка результатов, файл ссылок с автозаполнением, кнопки «Цены НОСИМО», «Запустить»/«Остановить», «Справка», прогресс по магазинам и лента результатов.

## Основная папка

Приложения при первом запуске спрашивают основную папку и дальше работают в ней (`--root`):

```
<основная папка>/
  Ссылки/links_tv.xlsx, links_smart.xlsx, Резервные копии ссылок/   — рабочие ссылки
  2026-10-22/ТВ/, Смартфоны/, Ссылки/ (копия), Скриншоты/ТВ.png, Смартфоны.png, Логи/
```

Логика путей — `layout.py`; прежние `links.xlsx` / `links_smart.xlsx` переносятся в «Ссылки» при первом обращении.

## Запуск из терминала

```bash
.venv/bin/python run.py --file ~/Desktop/ТВ.xlsx --root ~/Documents/Мониторинг\ цен       # как в приложении
.venv/bin/python run.py --tables ТВ --stores wb,ozon            # таблицы из папки проекта, результат в results/
.venv/bin/python run.py --articles UE32H5000FUXRU,HW-Q600F/RU
.venv/bin/python fill_links.py --file Смартфоны.xlsx --links links_smart.xlsx   # автозаполнение ссылок (--stores mvideo — только М.Видео)
.venv/bin/python nosimo.py --file ТВ.xlsx                       # цены НОСИМО с galaxystore.ru
```

## Правила

| Магазин | Как |
|---|---|
| М.Видео, DNS, МТС, samsungstore | по ссылке из файла ссылок; проверка карточки: ТВ — по артикулу, смартфоны — по модели из «Наименования» |
| Ozon | первые 15 плиток по артикулу: самая низкая цена **с Ozon-картой** среди товаров с отзывами (нет отзывов — самая низкая); без уценки и зарубежных |
| Wildberries | первые 15 плиток: самая низкая цена среди товаров с отзывами (нет — самая низкая) |
| НОСИМО | кнопка «Цены НОСИМО» (galaxystore.ru, цена даже без наличия; нет на сайте — «-») или 1С |

Автозаполнение ссылок: ТВ — М.Видео (самая дешёвая в наличии, любой продавец) и DNS; смартфоны — М.Видео (карточка самого М.Видео, иначе самый дешёвый продавец маркетплейса без зарубежных версий), DNS, МТС, samsungstore по модели/памяти/связи. Не найдено — прежняя ссылка остаётся. Перед каждым сбором цен по смартфонам ссылки М.Видео обновляются автоматически (`run.py --no-links-refresh` — отключить).

«-» — нет в наличии. Ошибка сайта — остаётся прежнее значение. Красный — цена конкурента ниже НОСИМО.

## Файлы

- `config.py` — таблицы (колонки, заголовки-подписи), правило подсветки.
- `run.py` — сбор цен; `stores.py` — магазины; `matching.py` — артикулы ТВ; `excel.py` — запись в таблицу.
- `fill_links.py`, `phone_sites.py`, `phone_matching.py` — автозаполнение ссылок; `make_links_template.py` — синхронизация файла ссылок с таблицей.
- `nosimo.py` — цены НОСИМО; `screenshot.py`, `excel_html.py` — скриншот таблицы.
- `desktop_app.py` — приложение для Windows; `tools_main.py` — вход скриптов в собранных версиях; `paths.py` — где рабочие файлы.
- `app/` — приложение для Mac; `build_dmg.sh`, `build_windows.ps1`, `installer.iss` — сборка установщиков.
