# Изменение формата samsungstore — 17 ноября 2026

В 1.5.0 сборщик ожидал `__NEXT_DATA__` и прежнее Redux-состояние каталога. Текущий сайт использует серверный Next Flight-поток, `initialProductsData` и TanStack `dehydratedState`. Ответ HTTP 200 с правильным СПБ приходил, но старый разбор выдавал общую ошибку подтверждения региона. Повторные проходы читали тот же неподдерживаемый формат.

Исправление поддерживает оба формата, не исполняет JavaScript, разрешает ссылку выбранного `currentRegion`, проверяет неоднозначность данных. Список доступных городов не считается подтверждением региона. Цена СПБ и полный артикул по-прежнему проверяются отдельно. Текстовые Flight-записи пропускаются по длине UTF-8, чанки объединяются до разбора.

Контрольные запросы тем же HTTP-клиентом приложения: обе страницы каталога (47 товаров), UE43F6000FUXRU — 26 990 ₽, QE32LS03CBUXRU — 46 990 ₽. UE32H5000FUXRU и UE32F6000FUXRU в текущем каталоге не найдены. Это результаты проверки 17 ноября, не постоянные значения.

Проверки: 67 unittest, desktop selftest, независимое ревью без существенных замечаний. Сборка исправления проверочная; публичный релиз автоматически не обновляется.
