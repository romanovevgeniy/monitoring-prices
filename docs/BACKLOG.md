# Бэклог

## Подключение нового конкурента пользователем

Статус: отложено; конкретный магазин пока не выбран.

Раздел «Конкуренты»: название, город, пробная ссылка, настройка и подтверждение цены/артикула/наличия/региона. Первый этап — ручные ссылки «Артикул → карточка» и тест нескольких товаров. Затем — поиск по каталогу при наличии подходящего адаптера. Подключение любого сайта одной ссылкой не гарантируется: антибот, авторизация и региональные цены могут потребовать отдельного сборщика.

Источник включается в отдельный шаблон. Действующий samsungstore СПБ и старые магазины сохраняются. Экспорт — отдельная копия согласованного оформления Excel; существующие таблицы не меняются автоматически.
