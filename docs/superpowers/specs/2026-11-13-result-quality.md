# Достоверность результатов мониторинга

Пользователь одобрил три улучшения: актуальность цен; понятные ошибки и повтор неудачных позиций; итог сравнения с НОСИМО. Реализовать в Qt Windows и SwiftUI macOS, сохраняя оформление Excel и оба сценария ТВ/смартфоны.

Статусы хранятся в соседнем JSON, ключ — артикул и магазин, а не номер строки. Успех содержит время проверки, ошибочный результат сохраняет старую цену и время последнего подтверждения. Старые таблицы без метаданных показываются как «Не проверено», не как свежие. Несовпадение сохранённой цены/шаблона или повреждённый JSON не дают ложной актуальности. Статус «сегодня» определяется локальной датой проверки, вчерашние данные показываются прежними. После правки НОСИМО статусы конкурентов сохраняют смысл.

Повтор запускается из результата, только для точных пар артикул–магазин со статусом ошибки. Manifest связывается с исходной таблицей и шаблоном, проверяется перед сетевыми запросами; нет в наличии, отсутствие ссылки и не обработанные при остановке позиции не выдаются за успешно проверенные. Успешные результаты не перепроверяются и не затираются. Результаты разных дней не получают ложные свежие статусы.

Итог и фильтры: все товары, конкурент дешевле, ошибки, неподтверждённые цены. Сравнение считается только по свежей числовой цене при положительной цене НОСИМО. Показываются число товаров, число обновлённых, число товаров с более дешёвым конкурентом, максимальная разница в рублях и число неподтверждённых. Правки исходной Excel-таблицы/порядка строк не меняют принадлежность статусов другому товару.

Ошибки процесса содержат понятную причину и действие; технический журнал доступен отдельно. Ошибка записи статусов не маскирует результат свежим. Публичный релиз в эту задачу не входит.
