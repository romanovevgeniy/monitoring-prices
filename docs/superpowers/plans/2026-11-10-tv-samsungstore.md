# Мониторинг ТВ: шаблоны и надёжность Excel

Цель: сохранить прежний сценарий всех магазинов и добавить отдельный шаблон samsungstore СПБ в сравнении с НОСИМО.

## Актуальные требования пользователя

- «Все магазины»: прежние М.Видео, DNS, Ozon, Wildberries, ссылки и выбор магазинов сохраняются.
- «samsungstore · Санкт-Петербург»: только этот сайт; город ответа и тип цены должны соответствовать spb, артикул проверяется полностью.
- Отдельный Excel СПБ содержит только артикул, samsungstore СПБ и НОСИМО. Используется прежняя колонка М.Видео с новым заголовком; остальные колонки удаляются только в копии СПБ.
- Дизайн исходного Excel сохраняется: стили ячеек, шрифты, рамки, числовые форматы, размеры оставшихся колонок, высота строк, объединения. Красная подсветка «конкурент дешевле НОСИМО» остаётся.
- Ссылки, время и статусы — в логах. Дополнительные колонки разницы/статуса в Excel не добавляются.
- Таблицу СПБ можно выбирать как исходник следующего запуска. В ней доступен только сценарий СПБ; для всех магазинов выбирается прежняя исходная таблица.
