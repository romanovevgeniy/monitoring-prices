# Пошаговый мониторинг Windows и macOS

Выбор пользователя: второй интерактивный вариант «Пошаговый запуск», внедрить в обе нативные версии.

Одинаковые шаги: 1. Таблица — файл, шаблон, магазины, папка, ссылки. 2. Наши цены — предпросмотр и ручная правка НОСИМО, автозагрузка с galaxystore. 3. Сбор цен — проверка настроек, запуск, остановка, прогресс и результат. Предпросмотр справа сохраняет контекст. Назад и шаги недоступны во время сбора. Изменения НОСИМО сохраняются перед уходом со второго шага; ошибки валидации/конфликт файла оставляют пользователя на текущем шаге.

Переиспользуются существующие сборщики, шаблоны, безопасная модель WorkbookDocument и события прогресса. Новый общий workbook_preview.py предоставляет компактный JSON предпросмотра и атомарную правку НОСИМО; Qt использует его непосредственно, Swift — через встроенный Python. В предпросмотре СПБ старые цены М.Видео не выдаются за samsungstore. Оформление .xlsx не меняется.

- [ ] 1. Общий предпросмотр/правка и тесты: реальные данные, шаблоны, пустые цены, конфликт и атомарная валидация нескольких правок.
- [ ] 2. Qt: пошаговая компоновка и редактируемый предпросмотр; сохранить ссылки, папку, оба шаблона, результаты, редактор без Excel. Проверить переходы и блокировки настоящими Qt-тестами.
- [ ] 3. SwiftUI: те же шаги и поведение, нативный предпросмотр, правка НОСИМО через общий JSON-контракт. Проверить компиляцию и реальный экран.
- [ ] 4. Сборки и документация: включить helper в обе упаковки, проверить selftest, весь unittest, Swift build, скриншоты и независимое ревью.

Публичный релиз не запускается автоматически при выборе дизайна. Сначала конкретный проверенный результат для просмотра пользователем.
