# Windows без установленного Excel

Цель: просматривать таблицы мониторинга и результаты, редактировать НОСИМО и ссылки, сохранять .xlsx с исходным оформлением внутри Qt-приложения.

Решение: нативный QTableWidget и openpyxl, без новых зависимостей. Отдельная модель WorkbookDocument отвечает за разрешённые поля, валидацию, резервные копии, конфликт внешних изменений и атомарное сохранение. Диалог показывает листы, объединения, цвета, шрифты и размеры. Остальные ячейки защищены от правки. Редактирование недоступно во время сбора. Формулы не вычисляются: показывается численный кэш, если он есть, иначе сама формула с пояснением.

- [x] 1. Модель документа + тесты: редактируются только НОСИМО или URL магазинов; нельзя записать формулу/произвольный текст в цену, потерять оформление или затереть внешний результат. Резервная копия до атомарного сохранения, без изменений исходника при ошибках.
- [x] 2. Диалог таблицы: листы, прокрутка/поиск, форматирование и объединения, редактирование с сообщениями в строке состояния, Save/Close и защита несохранённых изменений. Тесты настоящих Qt-виджетов.
- [x] 3. Кнопки исходной таблицы, результата и ссылок открывают встроенный диалог, внешняя ассоциация .xlsx не используется. Блокировка правок при сборе. Расширить --selftest для собранного Windows exe: открыть, изменить, сохранить и проверить xlsx во временной папке без Excel.
- [ ] 4. Проверить Windows CI и установленный пакет, обновить справку и описание v1.3.0. Проверить сборки обеих платформ.
- [ ] 5. Запушить изменения и опубликовать v1.3.0 с готовыми Windows EXE и macOS DMG на GitHub и GitLab. Не использовать локальные старые установщики как новые.

Сохранение дизайна Excel — обязательное требование пользователя. Все изменения только в значениях разрешённых ячеек и прежней красной подсветке сравнения. Макросы и полноценный расчёт Excel-формул не входят в задачу.
