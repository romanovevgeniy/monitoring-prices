# Достоверность результатов Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Свежесть цен, повтор ошибок и итог сравнения в обеих нативных версиях.

**Architecture:** Общие Python-модули статусов/ошибок расширяют существующий JSON-предпросмотр. run.py записывает метаданные только после сохранения результата, Qt/SwiftUI используют один контракт и фильтры.

**Tech Stack:** Python/openpyxl/unittest, PySide6, SwiftUI/Observation.

**Spec:** docs/superpowers/specs/2026-11-13-result-quality.md

## Global Constraints

- Дизайн Excel не меняется, статусы — в соседнем JSON.
- Windows без Office; macOS нативный SwiftUI.
- Оба шаблона ТВ и смартфоны сохраняются.
- Старые/повреждённые метаданные никогда не подтверждают свежесть.

## Review Focus

- Успех/ошибка/остановка, повтор на следующий день и авария фоновой задачи.
- Изменение цены вручную, перестановка строк, разные шаблоны одного исходника.
- Точный повтор без декартова произведения товаров и магазинов.
- Нулевая/пустая НОСИМО и устаревшая дешёвая цена не создают ложный итог.
- Большой предпросмотр, фильтрация и редактирование правильной строки на обеих платформах.

## Tasks

- [x] 1. Тесты статусов/итогов/ошибок → падают; общий модуль и предпросмотр → проходят. Атомарный JSON, нормализация и валидация, без изменений xlsx.
- [x] 2. Тесты точного повтора и сохранения run.py → падают; интеграция сборщика, понятные события ошибок и manifest → проходят.
- [x] 3. Qt: статусы/фильтры/итог/кнопка повтора; проверка настоящего окна и тесты фильтрации/аргументов/ошибок запуска.
- [x] 4. SwiftUI: тот же контракт и управление повтором; компиляция, проверка упаковки новых модулей.
- [ ] 5. Полный unittest/selftest, независимое ревью ветки, документация и снимки Qt. Исправить замечания и повторить затронутые проверки.

## Ledger

Принято: сегодняшний статус относится к дате фактического подтверждения, а не к дате имени папки. Цены без метаданных не подтверждены. В этой задаче не добавляем историю запусков и восстановление после аварии.

Проверка первых двух задач: 51 unittest проходят. Ruling: повтор в новой папке дня использует прежний результат как источник цен конкурентов, а актуальную исходную таблицу — как источник НОСИМО и оформления.

Ревью: исправлены all-errors в all, пропуски ссылок, переназначение колонок компактного СПБ, проверка изменённого результата перед повтором, подсветка только fresh и отдельный skipped в обеих UI. 61 unittest и desktop selftest проходят; Swift build проходит (только прежние предупреждения путей CLTools). Qt-предпросмотр и фильтр ошибок проверены снимками. CUA не распознаёт standalone Swift-бинарник как приложение; автоматическая визуальная проверка macOS не выполнена. Новые модули включены в упаковку, дополнен smoke-test frozen preview.
